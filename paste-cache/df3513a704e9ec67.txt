1. Exa MCP Server (추천 1순위)

       - 용도: AI 기반 웹 검색 및 크롤링
       - 특징:
         - 실시간 웹 검색
         - LinkedIn, 논문, 연구 자료 검색 특화
         - 구글보다 정확한 AI 기반 검색
         - 라이브 크롤링 지원
       - 버전: 3.1.3 (최신)
       - 설치: npx -y exa-mcp-server
       - API 키 필요: Exa API 키 (exa.ai에서 발급)

       2. Tavily MCP (추천 2순위)

       - 용도: LLM 에이전트 최적화 웹 검색
       - 특징:
         - AI 에이전트를 위한 맞춤형 검색
         - 웹 추출 및 데이터 추출
         - RAG 컨텍스트 생성
         - Q&A 기능
       - 버전: 0.2.12 (최신)
       - 설치: npx -y tavily-mcp
       - API 키 필요: Tavily API 키 (tavily.com에서 발급)

       3. Super MCP Router (라우터 용도)

       - 용도: 여러 MCP를 하나의 인터페이스로 통합
       - 특징:
         - 이미 설치된 여러 MCP를 하나로 묶음
         - 단일 엔드포인트로 관리
         - 검색 기능이 아닌 라우터 역할
       - 버전: 2.2.0
       - 용도: 검색보다는 MCP 관리 도구

       4. AgentPMT MCP Router

       - 용도: 298개 이상의 도구 제공
       - 특징: Claude, Cursor, VS Code 등 다양한 플랫폼 지원
       - 단점: 너무 많은 기능 (오버킬)

       추천: Exa MCP Server

       사용자의 요구사항 "원하는 내용을 콕집어서 잘 찾아오는
       기능"에 가장 적합합니다:

       장점

       - AI 기반 검색 (의미론적 검색)
       - 구글보다 정확한 결과
       - 논문, LinkedIn, 연구 자료 특화
       - 현재 설치된 context7과 궁합 좋음
