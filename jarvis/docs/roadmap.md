### Task #22: 파일 줄 수 제한

**파일 성격별 권장 줄 수:**

| 파일 성격 | 권장 줄 수 | 분할 트리거 |
|----------|-----------|------------|
| Logic/Utils | 50~80 | 함수 3개+ 또는 복잡한 정규식 |
| UI Components | 100~120 | State 4개+ 또는 깊은 DOM |
| API/Server | 80~100 | 에러 핸들링이 비즈니스 로직 가림 |

**규칙:**
- 파일당 50줄 내외 (기본값)
- 공통함수 추출 → 50줄 미만
- 기존 코드는 점진적 적용
- 지침으로 설정, 주기적 분할

**장점:**
- 리팩토링 불필요
- 가벼움
- TS 타입 에러 검증 편함
