## 기술적 특징

1. **자연어 파싱 (NLU)**: 명령어 없이 의도 파악
2. **로컬 메모리**: SQLite 기반 프라이버시 보호
3. **브라우저 자동화**: Chrome Extension 연동
4. **병렬 처리**: 독립 작업 동시 실행
5. **학습**: 패턴 분석으로 더 정확한 제안

## 주요 기능 목록

### 1. 브리핑 (Briefing)

**트리거**: `/j` 또는 `/j 오늘 뭐해?`

- 날씨 정보 (체감온도, 옷차림 추천)
- 오늘 일정
- 대기 중인 작업 (긴급도별)
- 습관 진행률
- 프로젝트 빌드/테스트 상태
- GitHub PR, 이슈, 리뷰 요청
- 클라이언트 작업 현황
- 운동/식단 상태

### 2. 작업 연속성 (Remember)

**트리거**: `/j 어제 뭐했더라?` `/j 하던 거 계속`

- 최근 3일간 작업 기록 조회
- 마지막 작업 파일, 진행률 표시
- 다음 단계 자동 제안

### 3. 자율 작업 실행 (Do)

**트리거**: `/j 이력서 작성해줘` `/j 코드 리뷰 좀`

- 작업 분석 → 계획 수립 → 실행 → 결과
- 문서 생성, 코드 작성, 분석 등

### 4. 예약 자동화 (Book)

**트리거**: `/j 레스토랑 예약해` `/j 영화 잡아줘`

- 조건 수집 → 옵션 검색 → 선택 → 예약
- 브라우저 자동화 활용

### 5. 이벤트 계획 (Plan)

**트리거**: `/j 데이트 코스 짜줘` `/j 제주도 여행 플랜`

- 선호도 분석
- 시간대별 코스 구성
- 체크리스트 생성

### 6. 정보 검색 (Search)

**트리거**: `/j 근처 맛집 찾아봐` `/j 리맥스 혹이 뭐야`

- 웹 검색 + 메모리 검색 통합
- 결과 요약 및 추천

### 7. 리마인더 (Remind)

**트리거**: `/j 3시에 회의 알림` `/j 메모해줘: 우유 사기`

- 메모리에 저장
- 시간 기반 알림

## 건강 관리

### 8. 운동 코칭 (Workout)

**트리거**: `/j 오늘 운동` `/j 오운완` `/j PT`

- 오늘의 운동 프로그램
- 운동 완료 기록
- PT 코칭 (폼 가이드, 세트/횟수)

### 9. 식단 관리 (Diet)

**트리거**: `/j 오늘 뭐먹지` `/j 식단` `/j 물 마심`

- 일일 식단 추천 + 레시피
- 칼로리/영양소 계산
- 수분 섭취 기록

### 10. 습관 트래킹 (Habit)

**트리거**: `/j 습관 추가 명상 20분` `/j 독서 했어`

- 습관 추가/삭제
- 일일 체크
- 연속 달성(스트릭) 관리

---

## 프로젝트 관리

### 11. 프로젝트 모니터링 (Project)

**트리거**: `/j 프로젝트 상태` `/j aifi 테스트 돌려`

- 빌드/테스트 상태 모니터링
- 실패 시 자동 알림
- 프로젝트 추가/제거

### 12. 클라이언트 작업 (Client Work)

**자동 활성화**: 외부인 문서 분석 요청 감지 시

- 프로젝트 폴더 자동 생성
- 6개 문서 체계적 생성 (병렬 처리)
  - research-insights.md
  - competitive-analysis.md
  - (기타 문서들)

### 13. GitHub 모니터링 (GitHub)

**트리거**: `/j PR 확인해` `/j 이슈 뭐있어` `/j 리뷰 요청`

- **PR 모니터링**
  - 오픈된 PR 목록 조회
  - 내가 생성한 PR 상태 확인
  - 머지 가능 여부 체크
  - CI/CD 상태 확인

- **이슈 트래킹**
  - 나에게 할당된 이슈
  - 멘션된 이슈
  - 레이블별 필터링

- **리뷰 관리**
  - 내가 요청받은 리뷰
  - 대기 중인 리뷰 알림
  - 리뷰 코멘트 요약

- **자동 알림**
  - 새 PR/이슈 생성 시 알림
  - 리뷰 요청 수신 시 알림
  - CI 실패 시 알림
