# Orchestrator Workflow

> 복잡한 리서치 주제의 체계적 조사 및 리포트 생성

## /orchestrator Command

복잡한 리서치 주제를 체계적으로 조사하고 종합 리포트를 생성합니다.

## 6-Step Workflow

```
┌─────────────────────────────────────────────────────────────┐
│ 1. Query Analysis                                            │
│    • 사용자 질문 명확화                                     │
│    • 핵심 키워드 추출                                       │
│    • 리서치 범위 정의                                       │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. Research Brief                                            │
│    • 리서치 질문 구조화                                     │
│    • 하위 질문 도출                                         │
│    • 가설 설정                                              │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. Strategy                                                  │
│    • 리서치 방법론 결정                                     │
│    • 데이터 소스 선택                                       │
│    • 에이전트 할당                                          │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. Parallel Research ⚡ Core Step                            │
│                                                              │
│    ┌──────────────┐ ┌──────────────┐ ┌──────────────┐       │
│    │   Academic   │ │   Technical  │ │     Data     │       │
│    │  (논문)      │ │ (GitHub,docs)│ │  (통계)      │       │
│    └──────────────┘ └──────────────┘ └──────────────┘       │
│           │               │               │                  │
│           └───────────────┴───────────────┘                  │
│                           │                                  │
│                    ┌──────────────┐                          │
│                    │  Fact-check  │                          │
│                    │ (검증)       │                          │
│                    └──────────────┘                          │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ 5. Synthesis                                                 │
│    • 다중 소스 통합                                         │
│    • 충돌 정보 해결                                         │
│    • 인사이트 추출                                          │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ 6. Report Generation                                         │
│    • 최종 문서화                                            │
│    • 구조화된 리포트                                        │
│    • 참조 정리                                              │
└─────────────────────────────────────────────────────────────┘
```

## Orchestrator Agent Structure

| Agent | Role | Responsibility |
|-------|------|----------------|
| research-orchestrator | 전체 조율 | 워크플로우 관리, 에이전트 할당 |
| academic-researcher | 학술 리서치 | 논문, 연구 데이터 수집 |
| technical-researcher | 기술 조사 | 기술 문서, GitHub, 공식 문서 |
| data-analyst | 데이터 분석 | 통계, 트렌드 분석 |
| fact-checker | 팩트 검증 | 정보 검증, 소스 확인 |
| research-synthesizer | 결과 통합 | 다중 소스 통합 |
| report-generator | 리포트 생성 | 최종 문서화 |

## Usage

```bash
# 명령어 호출
/orchestrator AI impact on encryption

# 또는 직접 Task 도구 호출
Task tool:
  subagent_type: general-purpose
  prompt: "Conduct comprehensive research using Open Deep Research
          methodology on topic: [topic]"
```
