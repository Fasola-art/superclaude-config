# Document Template

> Standard template for documentation

---

## Document Header

```markdown
# [Document Title]

> [One-line description]
> Version: [X.Y.Z]
> Last Modified: [YYYY-MM-DD]

---
```

## Standard Structure

### 1. Overview
- Document purpose
- Target audience
- Related document links

### 2. Core Content
- Key concept explanations
- Structure/diagrams
- Code examples

### 3. Usage
- Step-by-step guide
- Example code
- Caveats

### 4. Reference
- Related documents
- External links
- API documentation

---

## Markdown Rules

### Headings
```markdown
# H1: Document Title
## H2: Major Section
### H3: Subsection
#### H4: Detail Item
```

### Code Blocks
````markdown
```typescript
// Specify language
const example = 'code';
```
````

### Tables
```markdown
| Col1 | Col2 | Col3 |
|------|------|------|
| A    | B    | C    |
```

### Checklists
```markdown
- [ ] Incomplete item
- [x] Completed item
```

---

## File Naming Conventions

- Uppercase + hyphen: `DOCUMENT-NAME.md`
- Lowercase + underscore: `document_name.md`
- With version: `DOCUMENT-v2.0.md`
