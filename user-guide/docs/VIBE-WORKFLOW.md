# Vibe 워크플로우 가이드

> 키워드 기반 동작 제어 시스템

---

## 개요

Vibe 시스템은 자연어 키워드로 Claude의 동작 방식을 제어합니다.
13개의 Vibe Keywords와 4개의 Mode Keywords를 제공합니다.

---

## Vibe Keywords 워크플로우

### 1. 빠르게 (qk)

```
사용자: "빠르게 로그인 폼 만들어줘"
         │
         ▼
┌─────────────────────────────┐
│ 키워드 감지: "빠르게"         │
├─────────────────────────────┤
│ 동작:                        │
│ ├── Writer-Reviewer: 3회 제한 │
│ ├── 검증 단계: 생략           │
│ └── 즉시 코드 생성            │
└─────────────────────────────┘
         │
         ▼
   [결과물 바로 출력]
```

### 2. 실험 (exp)

```
사용자: "실험 모드로 새 알고리즘 적용해봐"
         │
         ▼
┌─────────────────────────────┐
│ 1. 현재 상태 스냅샷 생성      │
├─────────────────────────────┤
│ 2. 실험 코드 적용             │
├─────────────────────────────┤
│ 3. 결과 확인                  │
│    ├── 성공: "유지할까요?"    │
│    └── 실패: "롤백할까요?"    │
└─────────────────────────────┘
```

### 3. 동시에 (para)

```
사용자: "동시에 3개 API 만들어줘"
         │
         ▼
┌─────────────────────────────┐
│ 1. 태스크 분해                │
│    ├── API 1: /users         │
│    ├── API 2: /posts         │
│    └── API 3: /comments      │
├─────────────────────────────┤
│ 2. 의존성 분석                │
│    └── 독립적 → 병렬 가능     │
├─────────────────────────────┤
│ 3. 적응형 병렬 실행           │
│    └── 10개 동시 시작         │
└─────────────────────────────┘
```

### 4. 고쳐 (fix)

```
사용자: "이 에러 고쳐줘"
         │
         ▼
┌─────────────────────────────┐
│ 1. Error KB 검색              │
│    └── Jaccard 70%+ 유사 에러 │
├─────────────────────────────┤
│ 2. 유사 에러 발견?            │
│    ├── Yes: 이전 솔루션 적용  │
│    └── No: 새로운 분석        │
├─────────────────────────────┤
│ 3. Ralph Loop (최대 10회)     │
│    └── 자동 수정 시도         │
├─────────────────────────────┤
│ 4. 성공 시 KB 학습            │
└─────────────────────────────┘
```

### 5. 되돌려 (undo)

```
사용자: "방금 변경 되돌려줘"
         │
         ▼
┌─────────────────────────────┐
│ 1. 스냅샷 목록 조회           │
├─────────────────────────────┤
│ 2. 마지막 스냅샷 선택         │
├─────────────────────────────┤
│ 3. 롤백 실행                  │
│    └── 파일 복원              │
├─────────────────────────────┤
│ 4. "복원 완료"                │
└─────────────────────────────┘
```

### 6. 계속 (cont)

```
사용자: "어제 작업 계속해줘"
         │
         ▼
┌─────────────────────────────┐

├─────────────────────────────┤
```

## 키워드 조합 예시

```yaml
# 빠른 병렬 실행
"빠르게 동시에 3개 컴포넌트 만들어줘"
→ Writer-Reviewer 최소 + 병렬 실행

# 전략적 분석 후 수정
"strategic 모드로 분석하고 고쳐줘"
→ 트레이드오프 분석 + Error KB 자동 수정

# 실험 후 테스트
"실험 모드로 적용하고 테스트해줘"
→ 스냅샷 생성 + 코드 적용 + 테스트 실행
```
