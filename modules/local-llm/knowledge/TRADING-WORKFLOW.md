| 데이터 타입 | 설명 | 수집 주기 | 저장소 |
|------------|------|----------|--------|

| Order Book | 호가창 10단계 | 100ms | InfluxDB |

### 볼륨 분석 도구

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            볼륨 분석 체계                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  [TPO - Time Price Opportunity]                                            │
│  ───────────────────────────────                                           │
│  • 가격대별 체류 시간 분포도 분석                                            │
│  • POC (Point of Control): 최다 체류 가격대 = 가장 공정한 가격               │
│  • Value Area (VA): 70% 거래 집중 구간                                      │
│  • VAH (Value Area High): VA 상단 → 저항선                                 │
│  • VAL (Value Area Low): VA 하단 → 지지선                                  │
│                                                                             │
│  ★ TPO 확률 우위 전략:                                                      │
│  ├── 가격이 VA 내부: 횡보 확률 ↑ (레인지 트레이딩)                          │
│  ├── 가격이 VAH 돌파: 상승 지속 확률 ↑ (롱 추세 추종)                       │
│  ├── 가격이 VAL 하향 이탈: 하락 지속 확률 ↑ (숏 추세 추종)                  │
│  ├── POC 위 체류 시간 ↑: 상승 가능성 ↑                                     │
│  └── POC 아래 체류 시간 ↑: 하락 가능성 ↑                                   │
│                                                                             │
│  [볼륨 프로파일 - Volume Profile]                                           │
│  ───────────────────────────────                                           │
│  • P (POC): 최대 거래량 가격대 = 핵심 지지/저항                             │
│  • D (Developing): 실시간 POC 변화 추적 → 트렌드 방향 예측                  │
│  • B (Balanced): 균형 구간 = 횡보장, 방향성 모호                            │
│  • b (Breakout): 이탈 구간 = 추세 전환 신호                                 │
│                                                                             │
│  ★ P/D/B/b 매매 신호:                                                       │
│  ├── P 구간 접근 + 반등: 매수 신호 (POC = 강한 지지)                        │
│  ├── P 구간 하향 이탈 + 거래량 증가: 매도 신호 (지지 붕괴)                  │
│  ├── D가 P보다 위에서 형성: 상승 추세 확인 → 롱 유지                        │
│  ├── D가 P보다 아래에서 형성: 하락 추세 확인 → 숏 유지                      │
│  ├── B 구간 돌파: 새로운 추세 시작 신호                                     │
│  └── b 구간 확대: 변동성 확대, 추세 가속화                                  │
│                                                                             │
│  [VWAP - Volume Weighted Average Price]                                    │
│  ───────────────────────────────                                           │
│  • 거래량 가중 평균가 = 기관 평단가 기준선                                   │
│  • 가격 > VWAP: 매수 우위 (기관 수익 구간)                                  │

│  ★ VWAP 밴드 트레이딩 전략:                                                 │
│  ├── VWAP 터치 + 반등: 롱 진입 (기관 매수세 기대)                           │
│  ├── VWAP 하향 이탈: 숏 진입 또는 롱 청산                                   │
│  ├── +1σ 밴드 저항: 1차 익절 구간 (롱)                                     │
│  ├── +2σ 밴드 저항: 2차 익절 + 과매수 주의                                  │
│  ├── -1σ 밴드 지지: 1차 익절 구간 (숏)                                     │
│  ├── -2σ 밴드 지지: 2차 익절 + 과매도 주의                                  │
│  └── ±3σ 밴드 터치: 극단적 이탈 → 평균회귀 진입 검토                        │
│                                                                             │
│  ★ VWAP 앵커 전략 (Anchored VWAP):                                          │
│  ├── 실적 발표일 AVWAP: 실적 영향 평가 기준                                 │

┌─────────────────────────────────────────────────────────────────────────────┐
│                         오더플로우 분석 체계                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  [풋프린트 차트 - Footprint Chart]                                         │
│  ───────────────────────────────                                           │
│  • BID: 지정가 매수 / 시장가 매도 (매수벽)                                  │
│  • ASK: 지정가 매도 / 시장가 매수 (매도벽)                                  │
│  • 음의 델타 (Negative Delta): ASK > BID → 매도 압력 우위                  │
│  • 양의 델타 (Positive Delta): BID > ASK → 매수 압력 우위                  │
│                                                                             │
│  ★★★ 강력 신호 감지 (캔들 방향 vs 델타 불일치) ★★★                          │
│  ├───────────────────────────────────────────────────────────────────────┤ │
│  │  양봉 + 음의 델타 = 🔴 강력 매도 신호 (Hidden Selling)                 │ │
│  │  ├─ 가격은 올랐지만 실제 매도 압력 우위                               │ │
│  │  ├─ 기관/큰손의 물량 분산 가능성                                       │ │
│  │  └─ 숏 진입 또는 롱 청산 검토                                         │ │
│  │                                                                       │ │
│  │  음봉 + 양의 델타 = 🟢 강력 매수 신호 (Hidden Buying)                  │ │
│  │  ├─ 가격은 떨어졌지만 실제 매수 압력 우위                             │ │
│  │  ├─ 기관/큰손의 물량 축적 가능성                                       │ │
│  │  └─ 롱 진입 또는 숏 청산 검토                                         │ │
│  ├───────────────────────────────────────────────────────────────────────┤ │
│                                                                             │
│  [클러스터 델타 - Cluster Delta]                                           │
│  ───────────────────────────────                                           │
│  • 가격대별 델타 누적 히트맵                                                │
│  • 불균형 탐지 (Imbalance): 한쪽으로 치우친 주문 흐름                       │

│  • 분출 패턴: 급격한 델타 변화 → 추세 전환 가능                             │
│                                                                             │
│  [CVD - Cumulative Volume Delta]                                           │
│  ───────────────────────────────                                           │
│  • 누적 델타 추세 = 실제 수급 방향                                          │
│  • 가격↑ + CVD↑ = 정상 상승 (추세 지속)                                    │
│  • 가격↑ + CVD↓ = 🔴 베어리시 다이버전스 (반전 임박)                       │
│  • 가격↓ + CVD↓ = 정상 하락 (추세 지속)                                    │
│  • 가격↓ + CVD↑ = 🟢 불리시 다이버전스 (반전 임박)                         │
│                                                                             │
│  [북맵 - Book Map]                                                         │
│  ───────────────────────────────                                           │
│  • 하얀색 매물대: 대량 지정가 주문 = 강한 지지/저항                         │
│  • Spoofing 탐지: 주문 후 취소 패턴                                        │
│  • 아이스버그 탐지: 분할 체결 패턴                                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

-- 종목 마스터
CREATE TABLE trading.stocks_master (
    id SERIAL PRIMARY KEY,
    symbol VARCHAR(20) NOT NULL UNIQUE,
    name VARCHAR(100),
    market VARCHAR(20),          -- NASDAQ, NYSE, KOSPI, KOSDAQ, CRYPTO
    asset_type VARCHAR(20),      -- STOCK, ETF, CRYPTO, FOREX, FUTURES
    tier INT DEFAULT 4,          -- 1: 핵심, 2: 관심, 3: 워치, 4: 유니버스
    sector VARCHAR(50),
    industry VARCHAR(50),
    is_active BOOLEAN DEFAULT true,
    monitoring_config JSONB,     -- 종목별 모니터링 설정
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 시그널 테이블
CREATE TABLE trading.signals (
    id SERIAL PRIMARY KEY,
    symbol VARCHAR(20) NOT NULL,
    signal_type VARCHAR(20),     -- BUY, SELL, HOLD, ALERT
    source VARCHAR(50),          -- NEWS, MACRO, TECHNICAL, COMBINED
    confidence DECIMAL(3,2),     -- 0.00 ~ 1.00
    reasoning TEXT,
    llm_model VARCHAR(50),       -- qwen-3b, qwen-7b, claude
    raw_output JSONB,
    created_at TIMESTAMP DEFAULT NOW(),
    expires_at TIMESTAMP,
    executed BOOLEAN DEFAULT false,
    result JSONB                 -- 실행 결과 추적
);

-- 뉴스 분석 결과
CREATE TABLE analysis.news_analyzed (
    id SERIAL PRIMARY KEY,
    news_id VARCHAR(100) UNIQUE,
    headline TEXT,
    source VARCHAR(50),
    published_at TIMESTAMP,

    -- 1차 분석 (젯슨)
    edge_priority VARCHAR(10),   -- LOW, MEDIUM, HIGH, CRITICAL
    edge_keywords TEXT[],
    edge_model VARCHAR(50),
    edge_processed_at TIMESTAMP,

    -- 2차 분석 (Mac Studio)
    sentiment VARCHAR(20),       -- POSITIVE, NEGATIVE, NEUTRAL
    category VARCHAR(50),        -- MACRO, SECTOR, COMPANY, EARNINGS
    affected_tickers TEXT[],
    summary TEXT,
    hub_model VARCHAR(50),
    hub_processed_at TIMESTAMP,

    -- 메타데이터
    embedding_vector VECTOR(768),
    created_at TIMESTAMP DEFAULT NOW()
);

-- 포트폴리오 현황
CREATE TABLE trading.portfolios (
    id SERIAL PRIMARY KEY,
    account_id VARCHAR(50),      -- 계좌 구분
    symbol VARCHAR(20),
    quantity DECIMAL(20,8),
    avg_price DECIMAL(20,8),
    current_price DECIMAL(20,8),
    unrealized_pnl DECIMAL(20,2),
    realized_pnl DECIMAL(20,2),
    weight DECIMAL(5,2),         -- 포트폴리오 비중 %
    tier INT,
    updated_at TIMESTAMP DEFAULT NOW()
);
