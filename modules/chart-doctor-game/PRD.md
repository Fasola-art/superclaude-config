# PRD - Chart Doctor Game

## 1. 목표
트레이더가 오더플로우 기반 차트를 게임처럼 학습하고, 진입 전 차트 상태를 빠르게 판단하도록 돕는다.

## 2. 핵심 사용자
- 오더플로우/풋프린트 초중급 트레이더
- 뉴스 이벤트에 흔들리는 매매를 줄이고 싶은 사용자

## 3. 핵심 모드
### 3.1 차트 이미지 퀴즈
- 입력: 클러스터 델타, 볼륨프로파일, 풋프린트 기반 차트 스냅샷
- 사용자 행동: 뒷부분 방향(상승/하락/횡보) 예측
- 결과: 정답/오답, 누적 정확도 제공

### 3.2 차트 종합건강검진
- 컨셉: 의사 캐릭터가 검진비를 받고 차트 건강도 진단
- 검진 항목:
  - 4분할 장기/단기
  - 이평선 장기/단기
  - 풋프린트 + CVD 델타
  - 클러스터 델타
  - 볼륨프로파일
  - TPO
  - VWAP
- 출력: 건강 점수, 오더플로우 혈액순환 상태, 매수/매도/관망 코멘트

### 3.3 개미를 흔들어라
- 뉴스 이벤트로 군중심리 왜곡 체험
- 규칙:
  - 호재 뉴스 -> 덤핑
  - 악재 뉴스 -> 매집
- 목표: 스마트머니 의도(덤핑/매집)를 맞추며 점수 획득

## 4. 성공 지표
- 퀴즈 10문제 기준 정확도 60% 이상
- 건강검진 리포트에서 방향성 코멘트 생성률 100%
- 뉴스 게임 1세션 완료율 90% 이상

## 5. MVP 범위
- 단일 페이지 SPA
- 3개 모드 모두 동작
- 더미 데이터 기반 점수/리포트 생성
- 모바일/데스크톱 반응형

## 6. 제외 범위 (후속)
- 실시간 거래소 API 연동
- 결제/유료 검진
- 사용자 계정 및 랭킹
