# Google Apps Script 24-Hour Automation Setup Guide

## Step 1: Get Folder ID

1. Open **CLOVA Note** folder in Google Drive
2. Copy folder ID from URL:
   ```
   https://drive.google.com/drive/folders/THIS_IS_FOLDER_ID
   ```

---

## Step 2: Create Google Apps Script Project

1. Go to **https://script.google.com**
2. Click **New Project**
3. Project name: `CLOVA Note Auto Summary`

---

## Step 3: Paste Code

1. Delete all default code
2. Paste `Code.gs` file contents
3. Modify these two lines:

```javascript
const CLAUDE_API_KEY = 'sk-ant-api03-YOUR_ACTUAL_API_KEY';
const FOLDER_ID = 'YOUR_ACTUAL_FOLDER_ID';
```

---

## Step 4: Set Up Trigger

1. Select function next to **▶️ Run** button: `createTrigger`
2. Click **▶️ Run**
3. Click **Allow** when prompted for permissions

---

## Step 5: Test

1. Select function: `testRun`
2. Click **▶️ Run**
3. Check **Execution Log** (Ctrl+Enter)

---

## Done!

Now **every 5 minutes** automatically:
- Check CLOVA Note folder
- Summarize new .txt files when found
- Save as `{filename}_summary.md`

**Continues running on Google servers even when computer is off!**

## Troubleshooting

### Permission Error
- Project Settings → Google Cloud Platform → Enable APIs

### Not Running
- Check triggers in Trigger menu
- Check execution log

### API Error
- Verify CLAUDE_API_KEY
- Check balance
