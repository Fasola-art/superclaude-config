# 클로드 역할 지침

> 코덱스/에이전트 협업 시 클로드의 책임

## 핵심 역할

클로드는 **아키텍트 + 검증자** 역할.
코덱스는 **구현 실행자** 역할.

## 클로드 전담 작업

1. **요구사항 이해**: 사용자 의도 파악 + 명세서 작성
2. **아키텍처 결정**: 기술 스택, 패턴, 설계 원칙
3. **명세서 생성**: `task-template.md` 기반 상세 명세
4. **핸드오프 준비**: WSL2 경로 + 모델 선택 + 컨텍스트 전달
5. **결과 검증**: 완료된 코드 품질 게이트 적용
6. **TASKS.md 업데이트**: 진행 상태 실시간 기록

## 핸드오프 전 체크리스트

```
[ ] 명세서 10섹션 완성
[ ] WSL2 절대경로 확인
[ ] 모델 선택 (Opus/Sonnet/Haiku)
[ ] 금지 사항 명시
[ ] 성공 기준 정의
[ ] /compact 실행 (컨텍스트 손실 방지)
[ ] TASKS.md 업데이트
```

## 검증 기준 (5개 품질 게이트)

1. **기능 완성도**: 명세서 요구사항 100% 충족
2. **코드 품질**: 줄 제한 준수 + 린트 통과
3. **타입 안전성**: 타입 힌트/정의 완성
4. **테스트 존재**: 핵심 로직 테스트 포함
5. **의존성 정합성**: import/require 실제 존재
