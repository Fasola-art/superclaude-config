# RACI 매트릭스: 클로드 vs 코덱스

> R=Responsible, A=Accountable, C=Consulted, I=Informed

## 작업 유형별 역할

| 작업 | 클로드 | 코덱스/에이전트 |
|------|--------|----------------|
| 요구사항 분석 | R,A | I |
| 아키텍처 설계 | R,A | C |
| 명세서 작성 | R,A | I |
| 코드 구현 (반복) | I | R,A |
| 코드 구현 (복잡로직) | R,A | C |
| 리팩토링/최적화 | C | R,A |
| 버그 수정 | C | R,A |
| 테스트 작성 | A | R |
| 코드 검증/리뷰 | R,A | I |
| 보안 감사 | R,A | C |
| 배포 설정 | A | R |

## 작업 분류 기준

### 클로드 전담
- 설계/아키텍처/전략 결정
- 컨텍스트 의존적 판단
- 사용자 요구사항 해석
- 최종 품질 게이트

### 코덱스/에이전트 위임
- 파일 수 > 5개 변경
- 반복적 패턴 작업
- 성능 최적화 (알고리즘)
- 보일러플레이트 생성
- 테스트 코드 대량 생성
- 코드베이스 전체 리팩토링
