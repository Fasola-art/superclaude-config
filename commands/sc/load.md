# Load Context

Load context from external sources.

## Usage

```
/sc:load ./docs/PRD.md     # Load file
/sc:load --project         # Load project context
/sc:load --session last    # Load previous session
```

## Load Sources

- Files/documents
- Project settings
- Session history
- External references
