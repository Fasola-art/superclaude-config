# Test

Run tests.

## Usage

```
/sc:test                   # Full tests
/sc:test src/utils/        # Specific directory
/sc:test --watch           # Watch mode
/sc:test --coverage        # With coverage
```

## Supported Frameworks

- Jest
- Vitest
- Playwright
- Cypress
