# Workflow

Execute predefined workflows.

## Usage

```
/sc:workflow feature      # Feature development workflow
/sc:workflow bugfix       # Bug fix workflow
/sc:workflow release      # Release workflow
```

## Workflow Types

- feature: Feature development
- bugfix: Bug fixing
- refactor: Refactoring
- release: Release
