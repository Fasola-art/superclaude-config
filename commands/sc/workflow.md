# 워크플로우

사전 정의된 워크플로우를 실행합니다.

## 사용

```
/sc:workflow feature      # 기능 개발 워크플로우
/sc:workflow bugfix       # 버그 수정 워크플로우
/sc:workflow release      # 릴리즈 워크플로우
```

## 워크플로우 유형

- feature: 기능 개발
- bugfix: 버그 수정
- refactor: 리팩토링
- release: 릴리즈
