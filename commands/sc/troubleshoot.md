# Troubleshoot

Diagnose and resolve issues.

## Usage

```
/sc:troubleshoot           # Analyze recent errors
/sc:troubleshoot "build failed"
/sc:troubleshoot --logs    # Analyze logs
```

## Behavior

1. Analyze error
2. Search Error KB
3. Suggest solutions
4. Attempt auto-fix
