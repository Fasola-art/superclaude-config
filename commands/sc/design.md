# Design

Generate system or component designs.

## Usage

```
/sc:design auth-system        # System design
/sc:design UserProfile        # Component design
/sc:design --api /users       # API design
```

## Output

- Architecture diagram (ASCII)
- Interface definitions
- Data flow
- Dependency structure
