# SC 명령어 목록

SuperClaude 세부 명령어 모음입니다.

## 명령어

| 명령어 | 설명 |
|--------|------|
| `/sc:analyze` | 코드/프로젝트 분석 |
| `/sc:build` | 프로젝트 빌드 |
| `/sc:cleanup` | 코드 정리 |
| `/sc:design` | 시스템/컴포넌트 설계 |
| `/sc:document` | 문서 생성 |
| `/sc:estimate` | 작업 규모 추정 |
| `/sc:explain` | 코드/개념 설명 |
| `/sc:git` | Git 작업 도우미 |
| `/sc:implement` | 기능 구현 |
| `/sc:improve` | 코드 개선 |
| `/sc:load` | 컨텍스트 로드 |
| `/sc:spawn` | 에이전트 생성 |
| `/sc:task` | 태스크 관리 |
| `/sc:test` | 테스트 실행 |
| `/sc:troubleshoot` | 문제 해결 |
| `/sc:workflow` | 워크플로우 실행 |

## 모듈 명령어
