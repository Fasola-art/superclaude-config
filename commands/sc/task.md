# Task Management

Manage tasks.

## Usage

```
/sc:task list              # List tasks
/sc:task add "Complete implementation"  # Add task
/sc:task done 1            # Mark complete
/sc:task priority          # Sort by priority
```

## Behavior

- TodoWrite integration
- Task tracking
- Dependency management
- Progress reporting
