# 프로젝트 상태

현재 프로젝트의 진행 상황을 확인합니다.

## 동작

1. `.planning/STATE.md` 파일 로드
2. `todo.md` 태스크 상태 집계
3. 마일스톤별 진행률 계산
4. 최근 변경 파일 분석
5. 다음 우선순위 태스크 제안

## 표시 정보

- 전체 진행률
- 마일스톤별 상태
- Steel Thread 완료율
- 최근 완료 태스크
- 다음 작업 제안

## 사용 예시

```
/project-status
```
