`~/.claude/CLAUDE.md`를 읽고 토큰 효율성 분석 보고서를 생성하세요.

## 분석 항목

### 1. 중복 규칙 탐지
- 동일 의미 반복 규칙 쌍 목록
- 예: "Korean response" 관련 규칙이 여러 섹션에 존재하는지

### 2. 충돌 규칙 감지
- 서로 상충하는 규칙 쌍
- 예: 서로 다른 파일 크기 제한 규정

### 3. 미사용 슬래시 커맨드
- `~/.claude/commands/` 목록과 CLAUDE.md 참조 비교
- 목록에 없는 커맨드가 CLAUDE.md에 등록된 경우

### 4. 토큰 절감 추정
- 현재 추정 토큰: {현재 CLAUDE.md 파일 크기 기반}
- 중복 제거 시 절감 가능: {추정치}
- 목표: 현재 → 9k 토큰 (50% 감소)

### 5. 개선 제안 (실행 안 함)

우선순위 분류:
```
[HIGH] 즉시 제거 가능한 중복 (예: 3개 섹션에 걸친 동일 규칙)
[MED]  통합 가능한 유사 섹션
[LOW]  리팩토링 권장 (명확성 향상)
```

## 출력 형식

```markdown
# CLAUDE.md 분석 보고서

## 현황
- 파일 크기: XX줄 / ~XXk 토큰
- 섹션 수: XX개

## 중복 규칙 (X건)
| 규칙 A | 규칙 B | 권장 조치 |
|--------|--------|-----------|

## 충돌 규칙 (X건)
...

## 개선 제안 요약
예상 절감: ~Xk 토큰 (XX%)
```

## 주의

- **분석만** 수행, 파일 수정 없음
- 수정은 `/revise-claude-md` 사용
