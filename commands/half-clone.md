description: "컨텍스트 과부하 시 핵심 추출 + /compact 안내 (85%+ 트리거)"
---

컨텍스트가 85% 이상이거나 과부하 징후가 있을 때 핵심 정보를 압축 추출합니다.

## 실행 순서

### 1. 현재 세션 핵심 추출

최근 대화에서 다음 항목만 추출:

```markdown
# SESSION CORE - {타임스탬프}

## 현재 작업
{진행 중인 정확한 작업 1줄}

## 미해결 문제
{현재 막혀있는 문제}

## 중요 결정 사항
{이미 내린 아키텍처/방향 결정}

## 다음 즉시 할 일
{컨텍스트 리셋 후 첫 번째 할 일}
```

### 2. 파일 저장

`.claude/SESSION_CORE.md`에 저장 (프로젝트 루트 기준)

### 3. /compact 안내

```
컨텍스트 압축이 필요합니다.

저장 완료: SESSION_CORE.md
다음 단계:
1. /compact 실행
2. 새 세션에서: cat SESSION_CORE.md
3. 작업 재개
```

## 트리거 조건

- 컨텍스트 85% 이상
- 응답 속도 저하 감지
- 사용자 직접 호출

## 사용 예시

```
/half-clone        # 핵심 추출 후 compact 안내
```
