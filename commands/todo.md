# TODO 리스트

TODO 리스트를 확인하고 관리합니다.

## Usage
```
/todo           # 전체 TODO 리스트 표시
/todo add       # 새 태스크 추가
/todo done ID   # 태스크 완료 처리
```

---

**Execution:**

1. `~/.claude/todo.md` 파일을 읽어서 표시
2. 요약 통계 포함
3. 우선순위별 정렬

**파일 위치:** `~/.claude/todo.md` (단일 소스)
